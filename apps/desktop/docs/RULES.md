# RULES

## 진행 규칙

- 각 Phase는 순서대로 진행하며, 이전 Phase 산출물이 완성된 후 다음 Phase로 넘어간다
- 구현 관련 결정(기술 스택, 아키텍처)은 Research 단계 이전에 확정하지 않는다

## 문서 규칙

- 모든 문서는 한국어로 작성한다
- Spec 문서는 `docs/spec/`에서 관리한다
- 파일명은 `순번_이름.md` 형식을 따른다 (예: `01_prd.md`)
- changelog.md 파일은 추상화해서 작성한다

## 문서 일관성 규칙

- 각 문서는 이전 문서를 기반으로 작성하며, 내용이 상위 문서와 충돌하면 안 된다
- 상위 문서(PRD)의 내용이 변경되면 하위 문서(시나리오, 기능 명세 등)도 함께 검토하고 업데이트한다
- 문서 간 동일한 개념은 동일한 표현을 사용한다
