# PRD — AgentBridge

## 1. 문제 정의

현재 AI 코딩 에이전트 생태계에는 Claude Code, Codex CLI, Gemini CLI 등 여러 에이전트가 존재한다. 사용자는 각 에이전트의 강점을 활용하기 위해 여러 에이전트를 병행해서 사용한다.

그러나 각 에이전트는 독립된 별도의 앱으로 존재하기 때문에, 에이전트를 전환할 때마다 작업 맥락이 유지되지 않는다. 사용자는 매번 현재 상태를 직접 다시 설명해야 하며, 이전 에이전트의 작업 흐름이 다음 에이전트로 자연스럽게 이어지지 않는다.

이것이 핵심 문제인 **context handoff 단절**이다.

## 2. 전제 조건

- 각 에이전트는 독립된 앱으로 존재하며, 서로 맥락을 자동으로 공유하지 않는다
- 문제의 핵심은 모델 이름 차이가 아닌 분리된 앱 환경으로 인한 context 단절이다

## 3. 대상 사용자

- 여러 AI 코딩 에이전트를 병행 사용하는 개발자
- Claude Code와 Codex CLI를 함께 사용하는 사용자
- Gemini CLI를 포함해 여러 코딩 에이전트를 역할별로 나눠 사용하는 사용자
- 하나의 프로젝트에서 여러 AI 에이전트를 오가며 작업하는 사용자

## 4. 사용자 불편

에이전트를 전환할 때마다 사용자는 다음을 반복해야 한다:

- 현재 작업 목표 설명
- 지금까지 진행된 작업 설명
- 수정된 파일 설명
- 실패한 테스트 설명
- 남아있는 문제 설명
- 다음 에이전트가 수행할 작업 설명

## 5. 목표

여러 AI 코딩 에이전트를 하나의 앱에서 사용할 수 있도록 하여, 모델을 전환하더라도 작업 흐름과 맥락이 자연스럽게 이어지도록 한다.

사용자가 에이전트마다 별도의 앱을 오가거나 현재 상태를 반복 설명하지 않아도 되는 환경을 만드는 것이 핵심 목표다.

## 6. 기능적 요구사항

1. 하나의 앱에서 여러 AI 모델을 사용할 수 있어야 한다
2. 대화 중 모델을 자유롭게 전환할 수 있어야 한다
3. 모델 전환 시 이전 대화 맥락이 유지되어야 한다
4. 이전 대화를 이어서 진행할 수 있어야 한다
5. 사용자가 현재 상태를 반복 설명하지 않아야 한다

## 7. 제외 범위

- 시스템 아키텍처
- 기술 스택 및 구현 방식
- UI 구현
- 에이전트 간 자동화 (사용자 개입 없는 완전 자동 전환)
