# NFR — Non-Functional Requirements

## 1. 프라이버시

- AgentBridge 앱은 자체 클라우드 백엔드를 두지 않는다. 사용자 계정·구독 시스템을 운영하지 않는다
- 대화·IR·세션 데이터는 사용자 머신에 저장된다
- 단 모델 응답은 각 CLI(Claude Code, Codex CLI, Gemini CLI)가 호출하는 외부 LLM 서비스에 의존하므로, 해당 호출 자체는 본 항목의 적용 대상이 아니다

## 2. 호환성

- **OS:** MVP는 macOS만 지원한다. Windows/Linux는 향후 단계
- **에이전트:** Claude Code, Codex CLI, Gemini CLI를 지원한다
- 새로운 에이전트가 추가되더라도 기존 기능이 유지되어야 한다

## 3. 성능

- 에이전트 전환 시 IR 정제·주입으로 인한 지연은 최대 10초를 목표로 한다
  - 측정 구간 시작: 사용자가 모델 전환을 트리거한 시점
  - 측정 구간 종료(IR 검토 UI 없는 경로): 새 모델로 전환이 완료되어 입력이 다시 활성화된 시점
  - 측정 구간 종료(IR 검토 UI 있는 경로): IR 검토 패널이 화면에 표시되어 사용자가 검토를 시작할 수 있는 시점
  - 사용자 검토·편집 시간은 본 예산에 포함되지 않는다
- 전환 준비가 진행되는 동안 사용자가 현재 상태를 알 수 있도록 진행 상태와 경과 시간을 표시해야 한다
- 10초를 초과해도 자동 중단하지 않는다. 진행 표시기 옆에 보조 안내("예상보다 오래 걸리고 있습니다 — 취소할 수 있습니다")만 추가한다
- 앱 자체가 개발 환경의 자원을 과도하게 점유하지 않아야 한다

## 4. 신뢰성

- 앱이 비정상 종료되더라도 저장된 작업 맥락 데이터는 손실되지 않아야 한다

## 5. 사용성

- 채팅 인터페이스가 직관적이어야 하며 학습 비용이 낮아야 한다
- 설치 이후 별도의 복잡한 설정 없이 사용 가능해야 한다

## 6. 확장성

- 지원 에이전트를 추가할 수 있는 구조여야 한다
