# 사용자 시나리오

## 시나리오 1: 설계 후 같은 대화에서 구현 모델로 전환

**상황**
사용자가 AgentBridge에서 Claude와 아키텍처 설계 대화를 마쳤다. 이제 같은 맥락에서 Codex로 전환해 구현을 요청하려 한다.

**흐름**
1. AgentBridge에서 Claude와 설계 대화를 진행한다
2. 대화 중 모델을 Codex로 전환한다
3. Codex가 이전 설계 대화 내용을 파악한 상태로 구현 작업을 시작한다

**기대 결과**
사용자가 설계 내용을 다시 설명하지 않아도 Codex가 이어서 구현한다

---

## 시나리오 2: 구현 중 분석 모델로 전환 후 복귀

**상황**
사용자가 AgentBridge에서 Codex와 기능을 구현하던 중 대규모 코드베이스 분석이 필요해졌다. Gemini로 전환해 분석 후 다시 Codex로 돌아와야 한다.

**흐름**
1. AgentBridge에서 Codex와 구현 대화를 진행한다
2. 분석이 필요한 시점에 모델을 Gemini로 전환한다
3. Gemini가 이전 구현 맥락을 파악한 상태로 분석을 수행한다
4. 분석 완료 후 다시 Codex로 전환한다
5. Codex가 분석 결과까지 반영한 상태로 구현을 재개한다

**기대 결과**
모델을 오가는 과정에서 대화 맥락이 유지되어 작업이 끊기지 않는다

---

## 시나리오 3: 이전 대화를 다른 모델로 이어서 재개

**상황**
사용자가 어제 AgentBridge에서 Claude와 작업하다 중단했다. 오늘 Codex로 같은 작업을 이어가려 한다.

**흐름**
1. AgentBridge에서 이전 대화 히스토리를 불러온다
2. 모델을 Codex로 선택하고 대화를 재개한다
3. Codex가 이전 대화 내용을 파악한 상태로 작업을 이어간다

**기대 결과**
어제 어디까지 했는지 다시 설명하지 않아도 Codex가 바로 이어서 작업한다

---

## 시나리오 4: 역할별 모델을 반복 전환하며 작업

**상황**
사용자가 하나의 프로젝트에서 모델을 역할에 따라 나눠 반복적으로 사용한다. Claude는 설계, Codex는 구현, Gemini는 리뷰 역할이다.

**흐름**
1. AgentBridge에서 Claude와 다음 구현 범위를 설계한다
2. Codex로 전환해 구현을 요청한다
3. Gemini로 전환해 구현 결과를 리뷰한다
4. 피드백을 반영하기 위해 Claude 또는 Codex로 다시 전환한다
5. 전체 대화 맥락이 유지된 상태로 반복한다

**기대 결과**
모델을 반복적으로 전환하는 과정에서도 각 모델이 전체 작업 흐름을 파악한 상태로 역할을 수행한다
